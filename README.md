# GIZMO — archival mirror

This repository is an archival copy of **GIZMO**, last synced on October 4, 2026. It is not maintained and may be out of date.

**All GIZMO development, the stable and development branches, and all its work, live at the public repository [https://github.com/pfhopkins/gizmo](https://github.com/pfhopkins/gizmo).** Clone from there, and post issues, bug reports, feature requests and discussions there: they are not monitored here.

The User Guide is [here](http://www.tapir.caltech.edu/~phopkins/Site/GIZMO_files/gizmo_documentation.html), and the code website [here](http://www.tapir.caltech.edu/~phopkins/Site/GIZMO.html).
